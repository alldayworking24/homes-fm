# 레이아웃 정리 (2026-11, homes-fm)

휴대폰(360/390/430px) 중심으로 화면을 점검하고, 겹침·줄바꿈 문제만 CSS로 보정했습니다. 동작(JS)과 데스크톱(1280px) 표시는 바꾸지 않았습니다.

## 고친 것
| 화면 | 폭 | 문제 | 조치 |
|---|---|---|---|
| 룸체크 목록 카드 | 360 (430 이하 전반) | 리모델링 배지가 있는 호실에서 오른쪽 「완료 기한」 칸이 배지와 겹치고, 메타 문구가 좁은 칸에 갇혀 줄이 어색하게 꺾임 | 520px 이하에서 처리 상태·완료 기한을 제목 아래 한 줄로 내림(보수 현황 목록과 같은 방식). `#listWrap` 한정 |
| 리포트 하단 저장 바 | 360 | 「PDF 저장」이 두 줄(「PDF 저\n장」)로 꺾임 | 400px 이하에서 버튼 글자 줄바꿈 금지·좌우 여백·아이콘 크기 축소 (`.saveBar .btn`) |
| 사용법(tutorial.html) 상단 바 | 390 | 단계 제목이 길면 「n / 18」이 화면 밖으로 밀려 보이지 않음 | 600px 이하에서 구분선·여백 제거, 단계 제목은 말줄임, 단계 수는 우측 고정 |
| 공통(터치 크기) | 360~ | 유형 칩 33px, 도움말(?) 버튼 32px, 「추천값 적용」 31px | 560px 이하에서 칩 36px, 도움말 38px, 추천값 적용 36px |
| 화면 설명 문구 | 360 | 한글 단어 중간 줄바꿈(예: 「조회합니\n다.」) | 560px 이하 `.title p`에 `word-break:keep-all` |

## 확인했으나 수정이 필요 없던 것
- 로그인, 홈, 새 점검(점검 위치/지점 운영 정보 카드/긴급도), 점검 상세, 체크리스트 사진 영역(버튼 한 줄 + 썸네일 격자 + 「사진 N장」), 보수 상세(보수 전/후 사진, 부담주체 추천·청구 블록), 리포트, 더보기, 계정, 수리 이력, 카메라 모달, 사용법 안내 단계: 360px에서 페이지 가로 넘침 0건, 잘린 글자 없음.
- 기존에 정리한 사진 첨부 영역은 보수 상세(`#repairDetail`)의 보수 전/후 사진에서도 동일하게 보입니다.
